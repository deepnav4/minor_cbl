## Commands (from repo root)
- `npm run dev` — run web + api together
- `npm run build` — production build (web)
- `npm run typecheck` — typecheck all packages
- ⚠️ Don't run `npm run build` while `npm run dev` is running: both write to `apps/web/.next`, and the dev server can end up serving stale modules ("Element type is invalid … got: undefined"). Fix: stop dev, `rm -rf apps/web/.next`, start dev again.

## Environment
- Root `.env` (copy of `.env.example`), loaded by the api:
  - `PDF_SERVICE_URL` → structured-pdf-data base URL
  - `PORT` (optional, default 4000)
- `NEXT_PUBLIC_API_URL` for web (default http://localhost:4000)
